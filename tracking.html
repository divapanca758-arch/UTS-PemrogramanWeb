Tracking Pengiriman

File tracking.html — Informasi Pengiriman Halaman ini digunakan untuk mencari pesanan menggunakan nomor resi. Penjelasan Pengguna memasukkan nomor resi, kemudian menekan tombol Cari. JavaScript akan mencari nomor resi tersebut di variabel dataPesanan. Jika ditemukan, website menampilkan: - Nama pemesan. - Nomor resi. - Status pengiriman. - Ekspedisi. - Tanggal pengiriman. - Jenis paket. - Total pembayaran.
