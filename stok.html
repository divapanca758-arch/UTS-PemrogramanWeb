Informasi Stok Buku

File stok.html — Informasi Stok/Katalog Halaman ini menampilkan data buku dari variabel dataKatalogBuku. Penjelasan Halaman katalog menggunakan JavaScript untuk: 1. Mengambil data dari dataKatalogBuku. 2. Menampilkan judul buku, penulis, harga, dan stok. 3. Menampilkan gambar buku. 4. Menambahkan buku baru melalui DOM. 5. Mengarahkan pengguna ke halaman checkout ketika tombol Pesan ditekan.
